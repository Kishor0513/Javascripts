# 🚀 JavaScript 30+ Day Challenge

A comprehensive collection of JavaScript projects built as part of a 30+ day coding challenge. Each day features a unique project demonstrating different JavaScript concepts, DOM manipulation, and interactive web applications.

## 📋 Project Overview

This repository contains **100+** JavaScript projects, ranging from simple calculators to complex web applications. Each project is self-contained with its own HTML, CSS, and JavaScript files.

## 📁 Project Structure

Each project is contained in its own folder named after the project (e.g., `Calculator`, `Digital-Clock`).

```
Project-Name/
├── index.html (or similar)
├── style.css
├── app.js
└── assets/
```

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Kishor0513/Javascripts.git
   ```

2. Navigate to any project folder:
   ```bash
   cd Digital-Clock
   ```

3. Open the HTML file in your browser.
