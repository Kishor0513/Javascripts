# 🚀 JavaScript 30+ Day Challenge

A comprehensive collection of JavaScript projects built as part of a 30+ day coding challenge. Each day features a unique project demonstrating different JavaScript concepts, DOM manipulation, and interactive web applications.

## 📋 Project Overview

This repository contains **100+ days** of JavaScript projects, ranging from simple calculators to complex web applications. Each project is self-contained with its own HTML, CSS, and JavaScript files.

## 🎯 Projects List

### Days 1-10

- **Day 1**: Calculator - Basic arithmetic operations
- **Day 2-9**: Various JavaScript fundamentals
- **Day 10**: Digital Clock - Real-time clock with AM/PM format

### Days 11-20

- **Day 11-19**: Interactive projects with fonts and assets
- **Day 16**: Project with sound effects
- **Day 20**: Text Speed Control - Dynamic text display with speed adjustment

### Days 21-33

- **Day 21-33**: Advanced projects with custom assets and styling

### Days 34-99

- Continued learning and project development
- Multiple folders prepared for future projects

### Days 100-105

- **Day 100**: Quiz App - Interactive quiz application
- **Day 101-105**: Advanced web applications

### Bonus Projects

- **Random Color Generator**: Generate random color codes
- **Random Password Generator**: Create secure random passwords
- **Falling Ball**: Physics-based animation project

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling, animations, and responsive design
- **Vanilla JavaScript** - DOM manipulation, event handling, and logic
- **Assets** - Custom fonts, images, sounds, and music

## 📁 Project Structure

Each day's project typically includes:

```
DayX/
├── DayX.html (or index.html)
├── DayX.css (or style.css)
├── DayX.js (or app.js/script.js)
└── assets/ (images, fonts, sounds - when applicable)
```

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/Kishor0513/Javascripts.git
```

2. Navigate to any day's folder:

```bash
cd DayX
```

3. Open the HTML file in your browser:
   - Double-click the HTML file, or
   - Use a local server (recommended for better experience)
